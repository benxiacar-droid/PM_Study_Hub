## 1. 字节「豆包工作」正式发布，阿里「千问办公」、腾讯 WorkBuddy 三国杀升级

**发生了什么**：8月25日字节跳动发布企业级智能体产品「豆包工作」，与飞书深度打通，用户飞书登录后自动继承企业权限和知识上下文，还能调云端电脑做本地关机也能跑的长任务；同期字节把 TRAE、扣子（Coze）团队整体并入豆包体系。这是继阿里「千问办公」（8月已完成三款产品合并、接入钉钉/飞书/企业微信三大协同平台）、腾讯 WorkBuddy（7月 DAU 已破1300万）之后，大厂争夺「AI 办公入口」的第三枪，标志着持续半年的模型层「赛马」正式转向应用层的桌面/办公 Agent 入口大战。

**PM 视角**：这是目前中文互联网里最接近「企业级 Agent 到底怎么落地」的真实样本——三家打法完全不同：字节靠飞书生态绑定，阿里靠三合一整合钉钉体系，腾讯靠 C 端体验反哺 B 端订阅。但三家都在同一个坑上：企业客户真正在意的是权限隔离、数据安全、工作流定制，这些恰恰是「体验层 demo 好看」和「能不能真正卖进企业」之间的鸿沟。做企业 AI 落地的人应该把这仨当免费的活案例天天盯——他们的成败会比任何咨询报告都真实。

**潜在选题角度**：
- 「字节、阿里、腾讯都在抢的这个入口，企业客户真的买账吗？」（拆解三家打法+我的落地经验判断谁会赢）
- 「AI 办公 Agent 的 demo 都很炸，但企业采购看的是这三件事」

## 2. Manus 宣布恢复独立运营，创始团队原班留任

**发生了什么**：9月1日，通用 AI Agent 公司 Manus 正式宣布恢复独立运营，创始人肖弘、首席科学家季逸超、联合创始人张涛继续领导公司。背景：Manus 2025年底曾被 Meta 以约200-300亿美元收购，今年4月国家发改委外商投资安全审查工作机制办公室叫停了这桩收购，认定存在无法通过附加条件消除的国家安全风险——这是《外商投资安全审查办法》实施以来 AI 领域首个被公开叫停的案例。此后腾讯、真格等国内股东出资回购，Manus 于8月11日启动业务分离，9月1日正式官宣独立。

**PM 视角**：这不只是一则公司八卦，是一个关于「AI Agent 公司的数据主权/控制权/跨境投资」的活教材——尤其对想做出海产品或和外资合作的团队，这案例说明了监管红线到底卡在哪（控制权、数据处理、知识产权）。对求职者来说，Manus 作为「通用 Agent」赛道的头部样本，重新独立后大概率会加速招人和产品迭代，是值得关注的求职/合作标的。

**潜在选题角度**：
- 「一桩被叫停的300亿收购案，给所有做 AI 出海的产品经理提了个醒」

## 3. Anthropic 发布 Claude Fable 5.1 与 Mythos 5.1，重新洗牌产品命名体系

**发生了什么**：9月1日官方发布说明确认，Anthropic 推出 Claude Fable 5.1（面向长时间运行的智能体编码、知识工作与研究）及面向「Project Glasswing」邀测用户的 Claude Mythos 5.1，两者默认支持100万 token 上下文窗口、12.8万最大输出、常开自适应思考，定价与前代持平，缓存读取费用降至每百万 token 0.25 美元（降幅75%）。值得注意的是模型命名从「Opus/Sonnet/Haiku」体系切换为「Fable/Mythos」新命名。

**PM 视角**：抛开参数，这次真正值得职业选手关注的是两点：一是 Anthropic 又一次把「面向 Agent 编码/长任务」列为默认能力（100万上下文+常开思考），说明"能跑长任务的 Agent"已经是模型厂商的标配竞赛项，不是差异化卖点了——做产品判断优先级时要提前假设这个能力免费可得；二是命名体系换代（Opus/Sonnet→Fable/Mythos）背后是产品线重新分层（公开版 vs 邀测限量版），这是一次"用命名做产品分层"的教科书案例，值得单独拆一期讲给做 AI 产品的同行看。

**潜在选题角度**：
- 「Claude 悄悄换了产品名，这背后是一次典型的产品分层设计」

**来源**：

## 4. 快手旗下可灵AI获国家人工智能产业投资基金14亿元注资

**发生了什么**：9月1日消息，北京可灵科技（快手旗下视频生成模型公司）引入中国 AI 产业投资基金和正大机器人作为新增投资方，国家AI基金出资14亿元人民币获约1.14%股权，正大机器人出资约1.31亿元获约0.11%股权，双方均获得赎回权。此前可灵已完成近30亿美元融资，投后估值约180亿美元。

**PM 视角**：国家队真金白银进场头部视频生成模型公司，释放的信号是「AI 视频生成」被纳入产业战略级赛道，不只是内容创作工具。对企业 AI 从业者的启示：如果你所在行业和视频/多模态内容生产相关（营销、教育、直播电商），这类模型的商业化速度会比想象快，值得提前评估接入路径。带赎回权的条款也说明国家基金在用类似 PE 的方式做风险对冲，不是无条件输血——AI 大模型的"国家队投资"正在变得更专业、更商业化。

**潜在选题角度**：
- 「国家队砸14亿投的不是ChatGPT类产品，而是视频生成模型，这个信号很重要」

## 5. 2026年科技行业「AI裁员潮」持续，全年预计突破27万人

**发生了什么**：多方统计显示2026年已有超1430起裁员被归类为「AI相关调整」，全年预计突破27万人（2025年为24.5万）。典型案例：Meta 裁员约8000人（约占员工10%）同时把约7000人调入新设的AI重点岗位；IBM 自2024年9月以来累计裁员超1.5万；Intuit 裁减约3000个岗位（占比17%），明确表示是把资源转投AI；Atlassian 裁员约1600人（占比10%）用于"再平衡"资源向AI和企业销售倾斜。

**PM 视角**：这条数据背后有个容易被忽略的细节——大厂裁员的同时在"调岗到AI重点岗位"，说明真正在收缩的不是"AI相关工作"，而是那些没有跟AI能力结合的传统岗位。对想转行/在做AI PM的观众，这是一个很好的反焦虑素材：与其说"AI在抢工作"，不如说"不会用AI判断业务的人在被淘汰"——这正好呼应你的人设「讲真话、不贩卖焦虑」。

**潜在选题角度**：
- 「大厂一边裁员一边扩招AI岗，说明真正稀缺的是这种人」
- 「27万人被裁的AI裁员潮里，藏着一个被忽略的招聘信号」

## 6.（趋势观察，待核实细节）拾象播客：「高价值任务」取代 DAU，成为大模型公司新的第一优先级

**发生了什么**：拾象「AGI 备忘录」播客最新一期指出，大模型公司的竞争重点正从争抢 chatbot 泛用户 DAU，转向争夺"知识工作者的高价值任务"，coding 已从"重要场景之一"升级为几乎所有 AI Lab 的 T0 级战略。**具体期号/发布日期待核实**，但这个判断和近期字节/阿里/腾讯集体转向办公 Agent、Anthropic 持续加码长任务编码能力（见第1、3条）高度吻合，可以互相印证。

**PM 视角**：这其实是对第1、3条新闻的一个「元解读」——如果模型公司的战略重心真的从"泛用户体验"转向"少数高价值任务"，那意味着 To C 泛娱乐化的 AI 应用红利期在收窄，To B 场景化、垂直化的机会窗口在放大。这对你自己的内容定位是个背书：企业 AI 落地不是小众赛道，而是接下来两年行业资源真正倾斜的方向。

**潜在选题角度**：
- 「大模型公司集体不玩榜单了，都在抢这类任务——对做企业AI的人是好消息」

## 今日最值得做的 1 条

**推荐：第1条——字节「豆包工作」vs 阿里「千问办公」vs 腾讯 WorkBuddy 三国杀**

理由：
1. **时效性最强**：豆包工作8月25日刚发布，千问办公三大协同平台接入刚在8月底走完，是这两周企业 AI 领域最大的动作，现在讲还是热的，再拖一周就凉了。
2. **和人设契合度最高**：这是三条支柱里权重最大的「企业 AI 落地实战」，而且你有一线视角可以判断"demo 好看"和"企业真的买单"之间的鸿沟在哪，这是别的资讯号讲不出来的差异化。
3. **钩子强、能立观点**：可以直接开一个反常识钩子——「三个大厂都在抢的入口，我反而觉得最先掉队的是XX」，逼自己给出鲜明判断而不是罗列三家功能对比，符合"有观点不骑墙"的写作规则。
4. 第2、5条可以作为后续选题库的候选（Manus案例适合讲AI出海合规、裁员数据适合讲AI PM职业焦虑），但都不如第1条"现在拍现在能追上热度"。
