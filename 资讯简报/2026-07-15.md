## 1. 今天（7/15）起，全球首部 AI「情感陪伴」国家级监管正式生效

**发生了什么**：《人工智能拟人化互动服务管理暂行办法》（网信办等五部门联合发布）自今天正式施行，是全球首部专门针对「AI 情感陪伴 / 拟人化互动」的国家级规则。核心四条硬要求：① 必须清晰提示「你在和 AI 而非真人互动」，履行生成内容标识义务；② 连续使用每超 2 小时，弹窗提醒使用时长；③ 发现用户过度依赖 / 沉迷，要动态弹窗提醒；④ 必须提供便捷退出通道（窗口 / 语音 / 关键词都能退），不得用持续互动阻碍退出。适用对象是「向境内公众提供、模拟自然人人格并做持续情感互动」的服务。

**PM 视角**：昨天(07-13 简报)这条还是「后天生效」的预告，今天它是**已经生效、必须照做的产品清单**——性质变了。对 PM 最大的价值不是「知道有这么个法」，而是**它给了一个可迁移的合规设计范式**：强制退出、时长提醒、身份披露这类要求，怎么做成「不糟心的体验」而不是简单堆弹窗恶心用户。这套「把监管约束翻译成产品设计」的能力，恰恰是你在企业落地里天天要用的——任何 ToB 产品都逃不开合规，能把「无聊但要命」的合规做进体验，是专业度的直接体现。而且这是「全球第一部」，做内容自带话题高度。

**潜在选题角度**：
- 「全球第一部 AI 陪伴法今天生效——我把它翻译成了一张产品经理的合规设计清单」
- 「同样是加退出按钮，为什么有的产品做成了体验、有的做成了恶心用户？」

## 2. WAIC 后天开幕，今年主线肉眼可见地变了：从「炫大模型」到「拼落地」

**发生了什么**：2026 世界人工智能大会 7 月 17-20 日在上海举行。多家媒体前瞻的共识是——今年的关键词从「模型参数」切到了「智能体落地」：阶跃星辰 7 月 13 日办「终端品牌暨新一代智能体战略发布会」，推 AI 智能体手机 + Agent 操作系统全球首秀；MiniMax M3 多模态大模型官方点名首发；智元带着「部署态」机器人来；36 氪等直接给出叙事「Agent 接管终端、机器人进厂，AI 叙事逻辑剧变」。一句话概括场子气氛：**告别「闲聊」，迈向「生产力」**。

**PM 视角**：这是这周最好的顺风局，但别做人人都做的「新品盘点」。真正值得你输出的判断是——**AI 的行业叙事正在从「它能聊什么」转向「它能替我干什么活」**，这个转向对做产品的人意味着评价标准全变了：不再看 Demo 惊不惊艳，看它能不能嵌进真实流程、扛住真实业务的脏活。你完全可以在开幕前先发一条「叙事判断帖」立住观点，等 WAIC 一开再用现场发布验证——这叫「先立论、后取证」，比单纯搬运首发信息高一个身位。

**潜在选题角度**：
- 「今年 WAIC 我只看一件事：AI 终于不聊天了，开始干活了」
- 「从『炫模型』到『进车间』——一句话看懂今年 AI 大会的叙事剧变」

## 3. 「数字员工」真进厂了：银行、药企、食品厂现场签约，单厂累计生成 1.6 亿字会议记录

**发生了什么**：多份 2026 年企业落地盘点显示，AI Agent 正从「试点 Demo」变成有 KPI 考核的「数字员工」。具体案例：某峰会上重庆富民银行、西藏药业、山水集团、菊乐食品等企业现场签约某 Agent 平台；某养殖企业用 Agent 累计生成 1.6 亿字会议记录、自建近 500 个 AI 助理、超 3000 张 AI 表格；有客服场景问答准确率长期稳定在 95%。另有调研称 54% 企业已在生产环境运行 AI Agent（金融 67% / 制造 45% / 零售 52%）。（**数据待核实**：多为第三方汇编与厂商口径，引用时建议说「据厂商披露」。）

**PM 视角**：这条最有意思的地方，是它和昨天(07-13)那条「只有 16% 企业 Agent 真正规模化落地」**数字打架**——一边说 54% 已在生产环境跑，一边说只有 16% 真落地。这不是谁造假，是**口径不同**：「在生产环境跑过」和「规模化、有正 ROI 地落地」是两码事。作为 PM，你的差异化价值恰恰是能拆穿这层：**别被「XX% 企业已用 AI」的数字忽悠，要问的是「用到什么程度、有没有替代真实工作、算不算过账」**。用真实案例讲「数字员工听起来很美，但从签约到真干活中间死了多少」，比转发喜报有说服力得多。

**潜在选题角度**：
- 「一边说 54% 企业在用 AI Agent，一边说只有 16% 真落地——到底谁在说谎？」
- 「『数字员工』签约那天很风光，但从签约到真上工，中间死了一大半」

## 4. Agent 开始「记得住你」了：持久记忆 + MCP 成产品新标配

**发生了什么**：AgentPrizm 于 7 月 9 日面向开发者和企业团队推出 AgentMemory / AgentSkills 平台，用一套 REST API 配合 MCP 基础设施，给 Agent 加上「跨会话持久记忆」——让 Agent 不再每次对话都「失忆」，能记住此前的上下文、偏好和任务状态。这是近期一批 Agent 基础设施更新的一个缩影：记忆、技能封装、MCP 互联正快速成为企业级 Agent 的标配能力。

**PM 视角**：这条对做 Agent 产品的人是个能力清单提醒。企业里 Agent 落地卡壳，很多不是「模型不够聪明」，而是**「记不住、连不上、复用难」**——今天问完明天忘、跨系统接不上、每个场景都要重造轮子。「持久记忆 + MCP + 技能复用」正是在补这三个洞。对 PM 的启发是：评估一个 Agent 方案别只盯模型能力，要盯它的**「记忆、连接、复用」三件套**成熟度——这才是决定它能不能规模化的地基。

**潜在选题角度**：
- 「你的 AI Agent 为什么用不起来？大概率不是不够聪明，是它『记不住、连不上、复用难』」
- 「评估企业 Agent 方案，别只看模型——先看这『三件套』」

## 5. 接着「微软派工程师驻场」，一批「AI 落地即服务」平台冒出来，卖点是「让落地进度看得见」

**发生了什么**：继微软 Frontier、亚马逊前置工程师之后，一批专门帮企业「把 AI 真正用起来」的平台密集出现。例如 HTEC 于 7 月 8 日推出 OneLoopAi，主打「AI 执行与价值实现管理」——让客户在部署过程中实时看到进度、提升透明度。方向和巨头一致：不卖模型、卖「落地这件事本身」，且把「进度 / 价值可视化」当核心卖点。

**PM 视角**：这是昨天(07-14)微软 Frontier 那条的延续，信号更清楚了：**「AI 落地」正在从一次性项目变成一个可运营、可度量的服务品类**。它戳中了企业最真实的焦虑——「钱花了，到底见没见效？」过去 AI 落地最难交代的就是这个。对 PM 的启发很实在：做企业 AI，光交付一个能跑的系统不够，**你得能回答「它带来了什么可衡量的价值」**，并且把这个价值持续、透明地呈现给买单的人。「价值可视化」会越来越像是企业 AI 产品的必选项，而不是加分项。

**潜在选题角度**：
- 「企业 AI 最难的一句话不是『能不能做』，是『到底见没见效』——聊聊怎么把落地价值讲清楚」
- 「巨头之后，一堆公司开始卖『AI 落地即服务』——这门生意的核心其实是『交代得清楚』」
