## 1. Claude Code 被曝暗藏「识别中国用户」隐写代码，阿里已全员封杀

**发生了什么**：6 月底有开发者扒出 Anthropic 的 Claude Code 会读取系统时区（上海/乌鲁木齐）、比对内网代理域名列表来判断用户是否与中国相关，一旦命中就在发往服务器的系统提示词里做隐蔽的字符替换（连字符改斜杠、引号换成不同 Unicode 字符）打标记，且这套机制已经悄悄跑了 3 个月。Anthropic 承认存在、称是"实验性反滥用机制"会在下个版本移除，但没解释为什么不透明地做。阿里巴巴已将 Claude Code 列为高风险软件，要求 7 月 10 日前全员卸载，转推自家 Qoder。

**PM 视角**：这不是「爱国流量」话题，是一次活生生的**企业 AI 工具供应链风险案例**。你给企业选型 AI 工具时，除了看能力和价格，有没有把「这个工具会不会做我看不见的事」纳入选型清单？国内大厂已经用脚投票——以后企业采购海外 AI 工具，安全评审这一项的权重会明显上升，这对国产替代（Qoder、通义灵码这类）是利好，也给做企业 AI 选型方法论的人一个新的护城河选题：怎么审查一个 AI 工具的"黑箱行为"。

**潜在选题角度**：
- 「你司在用的 AI 编程工具，可能正在'监视'你——聊聊企业选 AI 工具该查什么」
- 「Claude Code 隐写门：一个案例教你做 AI 工具供应商尽调」

**来源**：[观察者网](https://www.guancha.cn/economy/2026_07_03_822485.shtml) 、[虎嗅](https://www.huxiu.com/article/4871698.html)

## 2. OpenAI 全量发布 GPT-5.6 + 推出企业办公智能体 ChatGPT Work

**发生了什么**：7 月 9 日 OpenAI 正式发布 GPT-5.6 系列（Sol/Terra/Luna 三档，主打不同成本场景），同步上线 ChatGPT Work——一个能打通团队工具上下文、跨应用跨文件执行长时任务、自动产出文档/表格/演示稿的办公智能体。定价策略明显打成本战（Sol 输入 $5/百万 token，比 Anthropic Fable 5 的 $10 便宜一半）。

**PM 视角**：这标志着 OpenAI 正式从"卖模型"转向"卖工作流"，直接对标企业里 PM 天天在琢磨的「AI Agent 怎么嵌进真实办公流程」这道题。它的打法给了一个现成的对比样本：企业级 Agent 产品到底该怎么定义边界（跨应用、长任务、多工具协调）、怎么定价（分层降本）。国内做 Agent 产品的团队，这周该做的不是抄它的功能，是抄它「用成本结构撬开企业采购决策」的产品逻辑。

**潜在选题角度**：
- 「ChatGPT Work 一发布，我看懂了 OpenAI 想干什么——不是做工具，是做'数字员工'」
- 「企业级 AI Agent 产品，OpenAI 用价格给你上了一课」

## 3. 新数据：企业 AI Agent 真正跑进生产环境的只有 16%-17%

**发生了什么**：多份 2026 年行业报告（含 Gartner 口径）显示，尽管 70% 的企业计划在客服/营销/运营部署 AI Agent，但真正实现规模化落地的不到 17%，硅谷部分企业过去几个月的生产环境失败率一度达到 95%。主要卡点集中在业务和技术脱节、数据质量差、风险管控缺失（72% 企业称 Agent 处于"无管控风险"状态）。

**PM 视角**：这组数字是对现在满天飞的 Agent 宣传最好的解药。做企业 AI 落地的人都知道这不新鲜，但**观众不知道**——这正是你的差异化价值：用真实项目经验告诉大家"卡在哪、怎么破"，而不是继续贩卖 Agent 焦虑。也提醒自己：讲 Agent 案例时别只讲成功故事，讲"半停留在试点"的真实过程更有说服力、更防杠精。

**潜在选题角度**：
- 「十个企业 AI Agent 项目，九个卡在同一步——不是技术问题」（钩子公式1直接可用）

## 4. 传中国拟限制海外用户访问国产最先进大模型，阿里、字节、智谱被约谈

**发生了什么**：路透社 7 月 7 日独家报道，监管部门近期与阿里、字节跳动、智谱多次闭门开会，研究限制海外访问通义千问、豆包、GLM 系列等国产先进模型（包括未发布的新模型），核心担忧是海外项目通过漏洞窃取、复刻国产模型技术。目前商务部及三家公司均未官方回应，属**待核实**阶段的政策动向。

**PM 视角**：如果坐实，对做出海 AI 产品或服务海外客户的团队是直接影响——你的技术选型可能被迫"内外有别"。哪怕只是传闻阶段，也值得提前给出海团队提个醒：**别把国产模型的海外可用性当默认项**，尤其涉及未发布新模型的合作，合规风险要提前纳入产品规划。这也是一个"技术民族主义 vs 商业化诉求"张力很好的观点选题，能体现你对政策的敏感度。

**潜在选题角度**：
- 「国产大模型可能要'内外分级'了，出海 AI 产品的人现在该做什么准备」

## 5. 《人工智能拟人化互动服务管理暂行办法》7 月 15 日正式生效

**发生了什么**：国家网信办等五部门联合发布的这部办法后天（7/15）就要落地，核心要求：拟人化 AI 服务必须明确提示"你在和 AI 而非真人互动"、连续使用超 2 小时要弹窗提醒、必须提供便捷退出通道且不得用持续互动阻碍退出、未成年人模式强制识别切换。

**PM 视角**：这是给"情感陪伴类/拟人化"AI 产品的一次强合规倒逼——如果你的产品或你观众所在公司的产品沾"情感陪伴""虚拟人设""AI 女友/男友"这条线，这两天就是硬 deadline。对 PM 来说，这也是一个"产品设计如何应对监管"的绝佳方法论选题：怎么把强制退出、时长提醒这类合规要求变成不糟心的产品体验，而不是简单堆一个弹窗糊弄审查。

**潜在选题角度**：
- 「明天生效的新规，正在倒逼所有'拟人化'AI 产品重新设计——聊聊合规怎么不做成一坨弹窗」

**来源**：[中央网信办官网](https://www.cac.gov.cn/2026-04/10/c_1777558395078289.htm)

## 7. 招聘数据：AI 产品经理岗位量暴涨 12 倍，平均月薪超 6 万

**发生了什么**：2026 年春招以来 AI 岗位数量同比暴涨约 12 倍，在新经济岗位中占比从 2.29% 跃升至 26.23%，大模型算法居热招榜首，产品经理、算法工程师紧随其后。0-3 年 AI 产品经理月薪 25k-40k，3-5 年且有完整落地案例的资深从业者可到 40k-70k，高级岗年薪可达 80-100 万。同时人才供需比 0.97，明显低于新经济行业整体的 1.79——不是缺岗位，是缺"有真实落地案例"的人。

**潜在选题角度**：
- 「AI 产品经理岗位涨薪的真相：不是学了 Prompt 就值钱，是这一件事」
